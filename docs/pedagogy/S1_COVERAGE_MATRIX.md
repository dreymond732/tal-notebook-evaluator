Le 18 septembre 2026, l’enseignant demande la préparation complète des sept TD S1 et de leurs correcteurs formatifs. Le contrôle final (TD8) est hors de ce lot et intégrera la progression complète.

## Contrat des TD formatifs

Chaque notebook demande des sorties `Résultat Qx :`. Le correcteur analyse statiquement le JSON, le code source hors commentaires et les sorties enregistrées ; il n’exécute jamais le code déposé. Les correcteurs acceptent les variations de solution compatibles avec les objectifs lorsque leurs marqueurs et indices substantiels sont présents.

## Bilan

Tous les éléments obligatoires des sources sont conservés, renforcés ou déplacés. Les seules suppressions concernent des formulations techniquement erronées, remplacées par les activités cibles identifiées ci-dessus.
