# Documents pédagogiques TAL

Cet espace contient les fiches du `TAL-Prof` : inventaires, matrice Python → TAL, spécifications validées, arbitrages et comparaisons d'outils.

Toute fiche distingue constat, hypothèse et décision enseignante. Les choix de bibliothèques précisent tâche, langues, données, versions, ressources de calcul, licence et articulation avec les LLM. Aucun document ne contient de données étudiantes réelles.

Pour préparer ou adapter un support, le Prof et le Designer réutilisent la [politique de tutorat](TUTORING_POLICY.md) et les [fiches structurées des séances](tutor_sessions.json). Ces sources définissent les modes TD/contrôle, les limites de l'aide et les notions autorisées exercice par exercice ; les instructions destinées au tuteur sont intégrées exclusivement aux métadonnées des notebooks.

La [spécification du TD2 S1](TD2_S1_SPECIFICATION.md) fixe sa matrice source → cible, les productions principales et complémentaires, le budget prévisionnel de deux heures et les limites du correcteur formatif. Elle conserve les sept groupes et les trois chaînes à nettoyer, sans anticiper les boucles.
