# Documents pédagogiques TAL

Cet espace contient les fiches du `TAL-Prof` : inventaires, matrice Python → TAL, spécifications validées, arbitrages et comparaisons d'outils.

Toute fiche distingue constat, hypothèse et décision enseignante. Les choix de bibliothèques précisent tâche, langues, données, versions, ressources de calcul, licence et articulation avec les LLM. Aucun document ne contient de données étudiantes réelles.

Pour préparer ou adapter un support, le Prof et le Designer réutilisent la [politique de tutorat](TUTORING_POLICY.md) et les [fiches structurées des séances pilotes](tutor_sessions.json). Ces sources définissent les modes TD/contrôle, les limites de l'aide et les notions autorisées exercice par exercice ; les instructions destinées au tuteur sont intégrées exclusivement aux métadonnées des notebooks.
