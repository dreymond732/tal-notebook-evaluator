Étape 1 · À commencer maintenant

Préparer, lire et valider le corpus de référence

Le premier objectif n’est pas de retrouver un nombre annoncé par un LLM : il est de disposer d’un texte nettoyé dont les choix de préparation peuvent être examinés et discutés.

Ouvrir le notebook 01 dans Google Colab

Le notebook est disponible dans le dossier public PT-LLMvsPy du dépôt du cours. Dans Colab, choisissez Fichier → Enregistrer une copie dans Drive, puis exécutez les cellules dans l'ordre. La bibliothèque Python et les documents de référence sont chargés depuis ce même dépôt.

Autre possibilité : télécharger le fichier 01_corpus_protocole.ipynb sur GitHub puis l'importer dans Colab.

  1. Exécuter le nettoyage

    Charger la version de référence de Faguet et les fonctions Python, lancer le traitement complet, puis sauvegarder le fichier texte obtenu.

  2. Lire le document nettoyé

    Ouvrir le fichier dans Bloc-notes ou un éditeur de texte. Vérifier les paragraphes, les titres, la ponctuation, les notes et les passages qui paraissent anormaux.

  3. Examiner les anomalies éventuelles

    Retrouver une zone par une suite exacte de caractères dans le texte original ; vérifier la fenêtre, identifier l’opération concernée et compter les occurrences d’un motif représentatif. Si aucune anomalie n’est observée, décrire les passages inspectés.

  4. Décider et comparer

    Conserver le traitement ou documenter une correction à tester dans une nouvelle révision. Comparer ensuite les premiers comptes lexicaux sur le texte original et le texte préparé.

Pourquoi cette première étape est indispensable

Le piège réel du texte : une ligne n’est pas une phrase

Dans le fichier de référence, une même phrase peut s’étendre sur plusieurs lignes typographiques. Les notes et les séparateurs ont aussi une présentation propre. Si un programme traite chaque saut de ligne comme une fin de phrase, il crée artificiellement des unités de mesure.

8 456
retours CRLF dans le fichier initial
6 479
recompositions de lignes dans le prétraitement actuel
20 + 4 + 3
séparateurs, appels de notes et blocs de notes repérés

Un bloc de note contient même des crochets internes : une suppression naïve arrêtée au premier crochet fermant peut conserver un fragment de note par erreur. Le traitement doit être vérifié sur le corpus réel, pas seulement sur des phrases d’exemple.

Exemple : compter les phrases

Un simple découpage aux signes . ! ? produit 3 987 segments non vides sur la source, sans traiter correctement toutes les abréviations. Il ne s’agit donc pas d’un nombre de phrases validé.

Exemple : compter des cooccurrences

Pour femme(s) et homme(s), un relevé exploratoire donne 98 lignes non vides communes, 203 segments issus de [.!?]+, ou 169 blocs délimités par des lignes vides.

Ces comptes reposent sur des unités différentes et des règles simples ; ils ne remplacent pas le comptage de référence à effectuer avec spaCy. Ils montrent l’ordre de grandeur possible des effets de segmentation, sans établir la cause des écarts entre LLM.

Règle commune aux quatre étapes

Contrat B — Chaque mesure doit pouvoir être retrouvée

Le contrat B est retenu pour le projet : une valeur isolée ne suffit pas. Chaque calcul ou rapprochement lexical doit conserver les informations nécessaires à sa reproduction et à son interprétation.

Source

Texte utilisé, version Git et empreinte ; opérations de prétraitement appliquées.

Mesure

Définition des unités (tokens, phrases, fenêtres), méthode, paramètres et valeur calculée.

Preuve

Passages retrouvables, indices dans le texte original et limites de l’interprétation.

01 · Préparation de la source

Nettoyer le corpus entier, chercher les défauts, décider de conserver ou réviser et produire les mesures lexicales de base.

02 · Description du lexique

Sur le texte nettoyé validé : fréquences, types, hapax, expressions et concordances. Définition à finaliser.

03 · Relations lexicales

Sur le même corpus : cooccurrences par phrase, variantes de fenêtres, marges et scores d’association. Définition à finaliser.

04 · Audit des résultats LLM

Confronter les comptes, les rapprochements G1–G6 et les citations aux résultats et aux passages vérifiables. Définition à finaliser.

⚑ Une condition de passage

Les notebooks 02, 03 et 04 utiliseront la version nettoyée retenue à l’issue de l’étape 1. Si cette version change, les résultats qui en dépendent doivent être recalculés.
